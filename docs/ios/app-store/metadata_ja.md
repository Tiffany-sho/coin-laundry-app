## 説明（4,000 文字以内）

```
コインランドリーの集金を、その場でスマートフォンに記録できるアプリです。硬貨の枚数を入れるだけで金額が計算され、店舗ごと・機器ごと・支払方法ごとの売上が自動で積み上がります。経費もあわせて記録すれば、月ごとの利益がグラフで分かります。

■ 集金をその場で記録
・設備ごとに硬貨の枚数を入れるだけ。金額は自動で計算されます
・合計金額だけを入力する方法も選べます
・電波が届かない場所でも入力でき、通信が戻ったときにまとめて送信されます
・同じ記録が二重に登録されないようになっています

■ 現金以外の支払いも方法ごとに
・PayPay、クレジットカード、交通系ICなど、受け付けている支払方法を店舗ごとに登録できます
・集金1件の中で、方法ごとに金額を分けて記録できます
・機種別に入力しているときは、設備ごとの内訳も残せます
・現金は登録しなくても常に記録されます

■ 経費と利益
・仕入れや修繕などの支出を、その日のうちに記録できます
・家賃や水道光熱費のように毎月かかるものは、固定費として登録すれば毎月自動で計上されます
・店舗ごとにも、店舗に紐づかない組織全体の支出としても記録できます
・その月のカテゴリ別の内訳を円グラフで確認できます
・売上から経費を引いた「月別利益」を、月ごとの棒グラフで確認できます

■ 売上を見る
・月別の売上を、店舗ごとの積み上げグラフで確認できます
・どの設備が稼いでいるかを機器別の内訳で確認できます
・支払方法で絞り込んで、現金とキャッシュレスの内訳を確認できます
・集金の履歴は日付順・金額順に並べ替えられます
・店舗ごとのページで、その店舗だけの売上と機器別の内訳を確認できます

■ 店舗と設備の管理
・店舗名、場所、概要、写真、設備を登録できます
・洗剤や柔軟剤の在庫が少なくなったら通知が届きます
・故障中の設備に印を付けて、メンバー全員で共有できます
・店舗が増えても都道府県で絞り込めます

■ 通知
・集金予定日の前日と当日にリマインダーが届きます
・通知が届く時刻は自分で選べます
・在庫が少なくなったとき、設備が故障したときにも届きます
・通知の種類ごとに受け取るかどうかを切り替えられます

■ チームで使う
・管理者、集金担当者、閲覧者の3つの役割があります
・集金担当者と閲覧者には担当する店舗を割り当てられます。担当していない店舗の集金・在庫・経費は表示されません
・誰がいつ何をしたかを記録した操作履歴を確認できます

■ サインイン
・メールアドレス、またはAppleでサインインできます

【プランについて】
無料のままお使いいただけます。無料では1つの組織につき3店舗まで登録でき、ご利用はおひとりまでです。

次の機能は、アプリ内の自動更新サブスクリプションでご利用いただけます。
・登録できる店舗数を増やす
・メンバーを招待して複数人で使う
・集金データをCSVまたはExcel形式で書き出す

購読の名称、期間、料金は、アプリ内の「プラン」画面に表示されます。購読は、期間終了の24時間以上前に自動更新を解除しない限り自動的に更新され、期間終了の24時間以内に更新分の料金が請求されます。購読の管理と自動更新の解除は、購入後にデバイスのアカウント設定から行えます。

利用規約とプライバシーポリシーは、アプリ内の設定画面からいつでもご確認いただけます。
```
